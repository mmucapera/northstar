## Development

Prefer working locally? You need **Node.js 20 or later** and **npm 10 or later** — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating). The required versions are pinned in `package.json` (`engines`) and enforced by `.npmrc` (`engine-strict=true`), so `npm install` fails immediately on an unsupported Node version instead of warning and breaking later.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
